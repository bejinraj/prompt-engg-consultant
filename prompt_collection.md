### Scoring logic

I would assess the options across **margin improvement, capital efficiency, and execution risk**, while giving additional consideration to how directly each solution addresses Apex's documented bottlenecks.

**1. Fix checkout → 2. Implement real-time inventory automation → 3. Optimize fulfillment → 4. Transition appropriate volume to 3PL → 5. Measure conversion, abandonment, inventory turns, fulfillment cost, and gross margin.**

Importantly, this does **not** mean Branch B or C should be discarded. Apex could use Branch A as the initial transformation and later evaluate **selective store closures or franchising** using the improved performance data.
